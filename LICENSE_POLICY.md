## What GPLv3 covers

The copyright holders of original JericoEngine code, original documentation and copyrightable modifications may distribute **their own contributions** under `GPL-3.0-only`. New Jerico-owned source contributions should use an accurate copyright statement and `SPDX-License-Identifier: GPL-3.0-only` when their provenance and ownership are established.

The GPLv3 declaration **does not imply that every file in this fork was authored by JericoFX** or that an upstream copyright holder's license was revoked. In a mixed-origin or modified file, preserve the original copyright/license notices and identify the separately copyrighted changes when applicable. Any existing, more specific third-party license or exception must be respected.

## Inherited O3DE code

The original O3DE-covered source remains available under the options in [LICENSE.txt](LICENSE.txt): Apache License 2.0 ([LICENSE_APACHE2.TXT](LICENSE_APACHE2.TXT)) or MIT ([LICENSE_MIT.TXT](LICENSE_MIT.TXT)). Those texts and applicable author/NOTICE/SPDX records remain in place. Apache-2.0 and MIT code can generally be combined with a GPLv3-covered work under their conditions, but this does not convert the upstream components into exclusively GPL-licensed material.

O3DE-derived code that is changed in this project may contain both inherited permissively licensed portions and Jerico-owned GPLv3-covered modifications. Retain source provenance and modification notices. No copyright assignment or universal license conversion is asserted.

## Separately licensed code, tools and assets

Vendored packages, fonts, textures, shaders, examples, SDK/toolchain components, Qt modules and external sources keep their individual licenses. The GPLv3 project policy does not automatically license user-created games or third-party assets. Inherited build/download catalogs are not proof that a component is shipped.

**Release status: legal redistributability NOT VERIFIED.** The [component-level compliance checklist](docs/legal/O3DE_LICENSE_COMPLIANCE_CHECKLIST_2026_10_13.md) remains open. Before distributing an Editor, SDK, runtime or game build, inspect actual direct/transitive artifacts, licenses (including any GPL/LGPL/exceptions or restrictive terms), linkage, required notices and source obligations, and produce a reconciled manifest. A README change or new license file is not evidence that all dependencies are compatible.

This document records the project's licensing choice and attribution boundaries; it is not a completed legal opinion.
