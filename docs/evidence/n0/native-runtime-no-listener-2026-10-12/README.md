# Disable the inherited remote console by default

The standalone room previously opened a TCP listener on `0.0.0.0:4600` even with Asset Processor disabled. The RED is retained in `../native-standalone-2026-10-12/{native-standalone-vulkan-attempt2,native-standalone-dx12-attempt1}/tcp-snapshot.json`. The cause is `log_EnableRemoteConsole=true`: the CrySystem update loop starts RemoteConsole independently of AP settings. The single source change makes that default false. It does not remove or alter the local console or the existing explicit remote-console opt-in.

The existing Profile launcher target built successfully in 18.297 seconds. Twelve recorded inputs remained unchanged; CrySystem.dll changed to SHA256 `4E026F4A3770607419221C81D2F2EBE04BBBD0A2BE3F0EC6F3E38CEB1CC75095`. Its size remains 1,094,144 bytes. This is a behavior fix, not a size reduction.

The parent ran the room on Vulkan and DX12 with `--bg_ConnectToAssetProcessor=false`, with no override of `log_EnableRemoteConsole`. Each run collected 20 process-owned TCP/UDP samples across approximately 25 seconds from startup. All samples and a later final check were empty; no Editor or AssetProcessor process was observed. Both backends visibly rendered the room, grid floor and doorway, and the logs show the fixture root spawnable ready. The local debug console was opened and observed on Vulkan. Captures are original resolution. This is not a packet trace or proof of absence between samples, nor verification of every local console command.

`dx12-attempt1` did not launch: the test guard still observed the previous Vulkan process immediately after termination. After confirming it had exited, `dx12-attempt2` executed once and passed. Processes were explicitly terminated after the observations; normal exit remains unverified. `ProbeRuntime.ps1` is the executed diagnostic harness (its later optional Attempt parameter preserves the rejected attempt); copy it into a new build evidence directory to replay with the existing audited build/cache, rather than writing into this published directory.

The original prefab SHA256 remains `FEE55849A032D29059D4369112047DC27E281D39631D0F0DF87D8BCF5EF517AA`; there were no scene or UV edits. Both logs retain the pre-existing missing `game.cfg` warning. DX12/Vulkan lighting parity, movement/collision, VR, Linux, complete package separation and source-free replay remain open. Explicitly enabling the remote console still uses its legacy binding behavior; this change accepts only the default-disabled path. AP bootstrap still requires its separate opt-out for this fixture launcher. N0 and the full engine goal remain incomplete.
