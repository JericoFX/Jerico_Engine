# EditorModeFeedback Implementation Plan

**Goal:** Integrar el feedback visual del editor en el owner nativo existente, conservando selección, foco de prefab y suspensión/restauración durante Play, sin otra DLL ni cambio de técnica.

**Architecture:** `JE::EditorRenderFeatures` incorpora los cuerpos bajo `JE::Editor::Render::Features`. Dos interfaces públicas viven en `Editor/Render/Features/Include/JE/Editor/Render/Features/EditorModeFeedback`; los cuerpos privados en `Editor/Render/Features/Source/EditorModeFeedback`. El módulo editor existente registra el componente una vez. La composición runtime no incorpora este componente ni sus herramientas.

**Tech Stack:** C++, CMake y Atom/Vulkan existentes. Sin paquetes, renderer, consola ni framework de selección nuevos.

**Spec:** `GOAL.md`, `docs/ROADMAP.md` N1/N11, `docs/architecture/JE_IDENTITY_AND_NATIVE_MODULES.md`, `docs/JE_LEAN_ENGINE_AND_AUTHORING.md` y directivas de unificación/autonomía nocturna del propietario.
