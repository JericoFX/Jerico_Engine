This local recipe adapts the Windows runtime package contract from
o3de/3p-package-source@70f0b7b5257bf7cf935bf1cfd270e1b53ccead18.
The original is vulkan-validationlayers-1.3.261-rev1-windows; this rebuilt
artifact has a distinct JE identity and a newly measured archive SHA256.
Compatibility with the historical binary is not asserted.

Vulkan-ValidationLayers v1.3.261 is upstream commit
a228e25346a931c791714977becb48b6702ec118. SourcePins.json records the seven
real source archives, commits, URLs and hashes; no test-only dependency is
substituted into the selected layer closure. The runtime retains original
robin-hood hashing and mimalloc2.0.7, pre-generated layer sources, C++17,
Windows/beta Vulkan declarations and the original Release deployment.
Both Release and Debug layers are included. The private SPIRV-Tools shared
auxiliary is built/installed as upstream defines it and is not deployed
as a validation-layer dependency.

Adaptations are Windows x64 Visual Studio2022/v143, a CMake3.5 compatibility
minimum isolated to mimalloc's private configure, and one provenance-only
replacement in the private SPIRV-Tools update_build_version.py work copy.
Its description identifies the exact SPIRV archive commit instead of
querying Git in the enclosing engine repository. Immutable sources are
unchanged; the original CHANGES version and validation APIs are unchanged.
Python is an explicitly local external generation tool and is not part of
this package or a runtime dependency of the engine, game or Editor.

Upstream licenses/notices are preserved in LICENSES: Apache2 for VVL,
Vulkan-Utility-Libraries and SPIRV-Tools; Vulkan-Headers Apache2/MIT scope;
the Khronos permissive SPIRV-Headers notice; Martin Ankerl's robin-hood
MIT and Microsoft/Daan Leijen's mimalloc MIT; AMD VMA MIT and Yann Collet's
embedded xxHash BSD2 notice. SourceNotices.txt preserves original source
comment notice blocks from the selected library source/header trees.
Full repository licenses and O3DE glue licenses are shipped separately.
