Only the library is built. Legacy level4 and multithread support are retained.
The new Windows artifact uses x64 v143, Release and the DLL CRT (/MD).
Debug CRT compatibility, compatibility with old O3DE binary packages, and
engine compression/Editor/runtime acceptance are not established here.

Security debt: this explicitly pinned historical source has not been upgraded
or certified against present vulnerabilities. Functional package checks do
not establish suitability for untrusted compressed input. Any upgrade needs
a separately audited source, format/consumer compatibility review and tests.
