Adaptations: v143 instead of the historical compiler, no Python bindings or
PythonPlugins product targets, explicit local native dependency discovery.
Only the original Windows stacktrace and rpath executable edits are applied
in fresh private OIIO work; immutable snapshots are unchanged. BuildNativeDependencies
preloads exact native configs/targets instead of removing FindOpenColorIO from
upstream. The three exact patched-file hashes/inverse proof are retained with
build evidence. Debug YAML uses its exported MDd target, not a Release path.

OIIO snapshot has exactly 1276 original regular files and omits only 15 approved
links in testsuite/texture-udim/ref and testsuite/texture-udim2/ref. Those links
point to verified regular test fixtures within the archive; upstream tests are
explicitly OFF. The codec/UDIM runtime sources remain. JPEG has the 510 original
exported regular members and omits seven administrative .git* export-ignore
members as committed upstream. Neither snapshot is described as a full Git-tree
byte match. Boost is the complete official source release (69,300 regular files),
not a synthetic archive of its superproject or submodules.

Only OIIO/OCIO public headers, Debug/Release DLL/import libraries and the original
six/eight Release native executables are staged. Private dependency libraries,
Python, NASM, b2, compiler tools and MSVC redistributables are not staged.
